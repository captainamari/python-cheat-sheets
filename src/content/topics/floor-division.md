## 核心机制

正数例子容易让人误以为整除就是去掉小数，但 -7 // 3 等于 -3，而 int(-7 / 3) 等于 -2。为了保持商与余数的恒等式，-7 % 3 等于 2；除数改为负数时，非零余数也会跟随除数的符号。divmod 一次返回同一套规则下的商和余数。

## 放到工程里

按固定长度切分带负偏移的时间轴、循环数组下标和分桶逻辑时，向下取整可能正是需要的语义。移植其他语言算法时必须核对负数除法约定，不要只跑正数测试。处理大整数时也不能先用 / 得到浮点数再 int，因为浮点中间值可能损失精度，甚至超出可表示范围。

## 容易混淆的边界

除数为零仍然抛出 ZeroDivisionError，整除不会自动返回零或无穷值。浮点操作的表示误差还可能影响边界，本文恒等式主要讨论精确整数运算。若业务真的要求向零取整，需要明确实现该约定，而不是把 Python 的 // 当成所有语言里的整数除法。

## 一分钟回答

我先说明取整方向，再用商乘除数加余数验证结果。Python 整数 // 向下，int(float) 向零，两者对负数不同。测试应包含正负组合、整除边界和零除数，大整数计算避免不必要的浮点中间值。
