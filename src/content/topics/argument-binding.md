## 核心机制

调用时，Python 将位置参数与关键字参数绑定到形参；同一个形参收到两份值会报 TypeError。/ 之前的参数不能按名称绑定，* 之后的参数要求明确写出名称。*args 收集额外位置参数，**kwargs 收集额外关键字，但它们不自动保证转发后的调用与下层接口兼容。

## 放到工程里

库 API 可以用仅位置参数保留将来重命名形参的空间，用仅关键字参数避免 timeout、retry 等开关被一串数字混淆。通用包装器需要检查调用形式时，可以使用 inspect.signature(...).bind，先验证绑定，再调用原函数；不过 bind 只验证参数分配，并不按注解检查类型或业务范围。

## 容易混淆的边界

把所有参数都塞进 **kwargs 会隐藏接口约束，错误可能一直传到深层才出现。转发时既显式传入 timeout 又保留 kwargs 中同名键，会产生重复值错误。向公共函数新增必填的仅关键字参数也会破坏老调用，不能因为写法更清楚就忽略兼容性。

## 一分钟回答

签名是一层可执行的接口约束。数据参数按自然方式传递，易混淆的行为选项使用仅关键字参数。包装器要验证重复和未知参数，业务校验仍独立进行。我会测试合法调用以及重复、缺失和错误传参方式。
