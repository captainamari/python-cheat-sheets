## 后续范围

S2 扩充到约 60 个知识点，增加收藏、错题队列、导入导出和更完整的复习能力。S3 再补齐约 120 个知识点和速查内容。S1 没有在线执行用户输入代码、账号系统或跨设备同步。

## 首次发布

空仓库先创建 main 基线，再通过功能分支 PR 提交 S1。合并前不会发布站点。管理员需要先将仓库 Settings → Pages 的 Source 设为 GitHub Actions；之后 main 推送触发发布。仅提交工作流不代表站点已上线。

## 视觉补充：迭代成形

按指定 algorithmic-art 方法加入确定性生成主图与独立 p5.js 画布，统一暖白、炭黑、陶土色的页面体系。阅读、练习和学习记录保留原有数据格式与路径。

- 新增 2 项算法测试，验证同种子复现、种子变化、默认配置不被修改和参数上限下的坐标边界；当前行为测试共 10 项。
- 构建共 21 个 HTML 文件（20 个站点页面与 1 个独立画布），搜索仍只索引 12 篇正文。
- 实际桌面浏览器已检查首页和正文；画布已验证种子切换、参数调整、重置和 PNG 导出。原有阅读标记仍可见。
- 自动化浏览器回归增加首页生成图形与页面宽度检查；最新 CI 结果见 PR #1。手机端覆盖由 Chromium 模拟环境提供，不表示真实 Safari 验证。
- 主站不加载 p5.js，不持续运行动画。独立画布使用模板规定的 CDN 脚本和字体，加载失败时显示提示。

算法设计、原始模板来源与许可见 [视觉说明](algorithmic-philosophy.md)。
