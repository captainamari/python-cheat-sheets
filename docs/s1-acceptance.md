# S1 实现与验收

## 范围

完成静态站骨架、12 个完整知识点、48 道练习、3 条学习路线、中文与英文术语搜索、本地学习记录和 GitHub Pages 发布工作流。

| 模块 | S1 交付                                                                    |
| ---- | -------------------------------------------------------------------------- |
| 阅读 | 直接回答、目标、代码高亮与复制、预期输出、正文目录、面试回答、来源、前后篇 |
| 内容 | 12 篇原创正文、12 个 Python 示例、12 份预期输出                            |
| 练习 | 12 道单选、12 道代码输出、12 道排障、12 道口述                             |
| 状态 | 单篇与随机练习、已提交答案恢复、独立阅读标记、客观题累计与最近自评         |
| 搜索 | Pagefind Extended 中文分词，12 个正文页面索引                              |
| 发布 | PR CI；main 构建并通过 GitHub Pages 工作流发布                             |

## 已完成的本地验证

- Astro / TypeScript 检查：0 错误、0 警告。
- 8 项行为测试：组卷、输出比较、重复提交、评分分离、会话恢复、损坏记录、阅读状态、存储写入失败时的内存回退。
- 12 个 Python 示例在 CPython 3.12 与 3.13 执行，输出与发布结果一致。
- 12 道代码输出题在 CPython 3.12 执行，与答案一致。
- 构建生成 20 个 HTML 页面，12 个知识页面建立中文搜索索引。
- 静态内部链接、资源路径与子路径部署检查通过。
- 单选题唯一最长选项为正确答案的比例为 3/12，作为编辑检查参考；没有按长度自动判定题目质量。

实际桌面浏览器已验证中文搜索、阅读标记刷新保留、四类题目作答、错题解析、已提交答案刷新恢复、本轮成绩分离及累计记录。远程 CI 与手机端流程结果在交付前补充。

## 后续范围

S2 扩充到约 60 个知识点，增加收藏、错题队列、导入导出和更完整的复习能力。S3 再补齐约 120 个知识点和速查内容。S1 没有在线执行用户输入代码、账号系统或跨设备同步。

## 首次发布

空仓库先创建 main 基线，再通过功能分支 PR 提交 S1。合并前不会发布站点。管理员需要先将仓库 Settings → Pages 的 Source 设为 GitHub Actions；之后 main 推送触发发布。仅提交工作流不代表站点已上线。
