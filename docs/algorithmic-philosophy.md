# Iterative Form · 迭代成形

一条线遵守简单规则，许多条线共同显现复杂形态。这个视觉主题把 Python 中反复求值、逐步迭代的过程藏进曲线的生成方式：每次只改变一点相位和半径，最终形成带有留白的环形织面。它不描绘语言徽标，也不把知识点画成网络图；它给学习站一个由代码本身形成的视觉记忆。

曲线由三个不同频率的谐波叠加。固定种子只决定初相位与缓慢扰动，线条之间保持连续关系，不给每个点添加随机抖动。轮廓需要精细控制：外侧舒展，内侧收拢，局部交叠形成密度变化。构图的工夫放在线间距、曲率和空白的共同校准上，让复杂性来自规则的反复运行。

颜色沿线束分组，而不沿每个点闪烁。炭黑承担文字，陶土、深青与橄榄色只出现在图形和少量强调位置。暖白底色让细线有纸面蚀刻般的层次。精细的线宽和透明度保持颜色相遇处的可辨识性，正文区域则使用实色背景，避免纹理侵入阅读。

时间由用户发起。主页展示同一默认种子的稳定结果，独立画布允许改变线束数量、起伏幅度、扭转程度与颜色。每次调整重新计算完整形态，绘制后停止；不通过持续动画争夺注意力。同一种子和参数必须重现相同几何，浏览器尺寸只改变显示比例。

实现的细致程度体现在约束中：首页 SVG 与 p5.js 画布共用一份生成函数；坐标保持在画布以内；参数有明确上限；默认画面在不加载脚本时依然可见。版式延续同样的秩序，以留白、细分隔线和清楚的文字层级组织导航、路线、阅读与练习。艺术存在于进入学习的瞬间，之后把空间交还给内容。

## 实现与维护

- `src/lib/art-field.ts`：唯一几何算法，纯函数，不依赖浏览器或 p5.js。
- `src/components/GenerativeArt.astro`：构建时生成首页 SVG，无动画、无外部资源依赖。
- `scripts/art/viewer.template.html`：Anthropic algorithmic-art 原始模板，保留其界面布局与样式。
- `scripts/build-art.ts`：把同一算法嵌入单文件 p5.js 交互画布；支持种子切换、参数、颜色、重置和 PNG 下载。
- `public/art/iterative-form.html`：生成产物，可单独打开；p5.js 与字体从 CDN 加载。它们不可用时显示说明，主站阅读、搜索和练习不依赖它们。

构建前运行 `npm run art:build`（已加入 build）。修改算法后，`npm test` 检查确定性、种子变化与坐标边界。开发时修改算法可直接观察首页；交互画布需重新生成。页面正文继续使用现有内容源与固定链接。

## 参考与许可

按用户指定的 [algorithmic-art SKILL.md](https://github.com/anthropics/skills/blob/main/skills/algorithmic-art/SKILL.md) 应用种子复现、参数探索和生成式构图。交互画布从其 viewer.html 模板改编，保留原有结构、字体和配色；本项目替换算法与参数，并补充导出、再生成、错误提示与可访问标签。模板版权属于 Anthropic, PBC，Apache-2.0 许可全文随画布发布于 `public/art/LICENSE-anthropic.txt`。生成算法为本项目独立编写。
