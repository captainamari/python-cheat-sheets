# 架构与边界

## 静态内容，局部交互

Astro 在构建时读取 Markdown / YAML 内容集合，经 Zod 校验后生成静态 HTML。知识点正文与示例无需 JavaScript 即可阅读。TypeScript 只负责分类筛选、Pagefind 搜索、练习和本地记录。

页面使用「迭代成形」暖白、炭黑与陶土色、系统字体和响应式布局，不依赖外部字体 CDN。表格和代码块内部可滚动；导航与练习支持键盘使用，页面尊重 reduced-motion。

## 单一内容来源

- 知识点文件名是稳定 ID，标题可修改，ID 不随标题改动。
- 正文与元数据位于 Markdown；练习另存 YAML，通过 `topicId` 关联。
- 目录、数量、路线页面与搜索索引从内容源生成。
- Python 示例只维护在 `examples/*.py`。Astro 构建时读取并高亮展示，`.out` 同时用于页面展示和实际执行校验。
- 路线只引用知识点，不复制正文。正文只在详情页建立搜索索引，避免首页目录占据搜索结果。

## URL 与部署

基础路径固定为 `/python-cheat-sheets/`，统一经过 `src/lib/urls.ts` 构建内部链接。详情 URL 为 `/topics/<id>/`，刷新与分享不依赖 SPA 回退。

Pagefind 使用 Extended 构建和 `zh-CN` 页面语言，构建时生成中文分词索引。搜索资源仅在搜索页按需加载。结果链接显式设置部署 base；输入通过 textContent 呈现，不拼接用户输入为 HTML。

练习只携带题目数据，不下载全部文章或媒体。S3 的 480 题随练习页提供，学习记录页也携带题目以构造队列与校验导入。当前保持单一静态构建；进一步扩容时再评估按专题拆分数据包。

## 速查视图

`/cheatsheets/` 汇总全部规则，`/cheatsheets/<category>/` 生成六个分类页。组件读取原有 topic 摘要、难度、岗位及 examples 源文件，不维护第二份速查正文。120 个条目在构建时渲染，关闭 JavaScript 后仍可阅读和展开代码。速查页不标记 Pagefind 正文，搜索结果继续指向知识详情。

客户端只筛选现有条目：关键词做 NFKC 和大小写规范化，以空白分词后要求全部词命中；分类、难度与岗位共同生效。关键词覆盖标题、摘要、标签、示例和输出，完整原理请使用全站搜索。筛选保存在 URL 查询参数中，刷新、分享与浏览器历史恢复不依赖本地学习记录。分类页固定自身分类，忽略查询参数中的其他分类。岗位标签表达复习重点，不代表其他岗位无需学习。

打印隐藏导航和筛选控件，保留当前可见条目；只打印已展开的示例。复制失败显示手工复制提示，空结果禁用打印。浏览速查、筛选、复制和打印不写入阅读、成绩或自评状态。详细正文仍沿用原有学习流程。

## 练习状态

本轮状态包含版本、练习范围、题目 ID 顺序、当前位置、已提交答案、已查看要点的开放题和完成状态。Fisher–Yates 洗牌后抽题，单篇练习使用该篇全部四道题。

状态转移约束：

1. 未提交答案不能进入下一题。
2. 已提交题不能再次计分，刷新后反馈仍可恢复。
3. 单选与代码输出为客观题；排障与口述为自评题。
4. 自评不计入客观题正确率，完成练习不自动标记阅读。
5. 恢复时验证版本、范围、题目引用、答案类型与结果一致性；失效练习不自动套用到新题库。

练习保存已经提交的答案，不保存未提交文本。只有一份当前练习；开始另一范围的新练习会替换当前会话，累计学习记录仍保留。

## 本地记录

`python-cheat-sheets:progress:v2` 保存阅读与主题累计成绩、收藏时间、每题最近答案/累计次数/连续答对次数/下次复习时间，以及导入世代 `generation`。历史逐次事件不无限追加，容量随题目数量增长。开放题不混入客观正确率。

没有 v2 时读取 v1 并在内存中迁移，首次保存写入 v2，原 v1 不删除。旧累计成绩没有题目明细，不能反推错题，逐题队列从 S2 新作答开始。未知版本或损坏数据阻止普通保存覆盖，明确提示；存储拒绝或配额失败时当前页面使用内存并提示刷新风险。

`python-cheat-sheets:session:v1` 仍兼容旧会话，新会话增加随机 ID 与 generation。题目提交以会话 ID + 题目 ID 标识，先保存成绩再保存会话；重试相同提交不重复累计，若成绩成功而会话保存中断，恢复当前题时可从最近提交恢复反馈。导入会改变 generation，旧会话不能恢复或继续写入新记录。队列变化不影响已经抽出的本轮题目。

复习安排：错误/again 立即到期，partial 一天后，连续正确/confident 分别为 1、3、7、14 天，之后维持 14 天；错误重置连续次数。以作答时刻加固定天数计算，不按当地零点。该规则只是复习建议。客观错题看最近一次错误，自评巩固看最近一次 again/partial，到期队列按 dueAt 判断，未作答题不加入。

## 备份导入

导出带 app、format、exportedAt 和 progress 的 JSON；支持 S1 原始记录导入。文件上限 5 MB，解析后严格检查数据结构、数值、时间与 ID，再按当前题库过滤未知引用并显示跳过数量。应用不会执行文件里的代码或 HTML。

选择文件只预览，不写入；点击明确的替换按钮才导入，不合并或累加成绩。先把当前原始文本保存到 `python-cheat-sheets:before-import`，再原子写入新快照；任一步写入失败都不覆盖当前学习记录。备份只保留最近一次导入前快照，可下载用于恢复。损坏记录也按原文备份，允许用户显式导入有效快照恢复。普通导出遇到无法解析的记录会导出原文而不是空进度。

多标签页通过 storage 事件刷新阅读与记录显示，但没有跨标签页写事务。同一练习建议只在一个标签页作答。跨设备通过手工导出/导入迁移，不提供账号或自动同步。记录是个人辅助信息，不作为可信成绩或考试凭证。

## 质量检查

内容检查验证元数据、ID、练习关联、选项、来源 URL 格式、示例存在性和路线引用。代码输出题实际执行；Python 示例跨版本比较标准输出。行为测试覆盖评分与存储边界，浏览器测试覆盖完整学习流程。

外部来源是否可访问不作为每次构建的阻塞网络依赖；编辑时核对来源。技术事实需要限定语言语义、CPython 实现、构建和版本。
